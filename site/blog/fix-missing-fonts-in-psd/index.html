How to Fix Missing Fonts in a PSD File

You open a downloaded album PSD and Photoshop warns that some fonts are missing, or text layers show a yellow triangle. It is one of the most common problems with templates, and it is easy to fix once you know the options. This guide explains why it happens and the safest ways to resolve it.

By Guru Moorthi · Updated 2026-10-24 · 4 min read

Why fonts go missing

PSD files store text as editable layers that refer to a font by name. The font itself is not embedded. If the template designer used a font you do not have installed, Photoshop cannot render it and shows a warning. The layer still looks correct until you edit it, because Photoshop keeps a preview, but as soon as you type, it switches to a substitute font.

Step 1: Identify the missing fonts

Go to Type > Manage Missing Fonts (or Resolve Missing Fonts in older versions). Photoshop lists every font that is not available. You can also select a text layer and look at the font name in the Character panel; missing fonts appear in square brackets.

Step 2: Check the download folder

Many template packs include a fonts folder or a text file listing the fonts used. Look inside the ZIP after extracting it. If fonts are included, install them before reopening the PSD.

Step 3: Install the font

On Windows

Right-click the .ttf or .otf file and choose Install for all users. Restart Photoshop so it picks up the new font.

On Mac

Double-click the font file to open Font Book and click Install. Restart Photoshop.

Only install fonts from trustworthy sources, and check the licence; many free fonts allow personal use only, while client albums are commercial work.

Step 4: Use Adobe Fonts if available

If you have a Creative Cloud subscription, Photoshop may offer to activate missing fonts from Adobe Fonts automatically. Accept, and the text renders correctly with a licence that covers commercial use.

Step 5: Replace with a similar font

If you cannot find the original font, choose a replacement in Manage Missing Fonts. Pick something close in style: a script for a script, a serif for a serif. After replacing, check every text layer because spacing and size can change. Our guide to choosing fonts for wedding albums lists dependable font styles.

Fixing layout after substitution

Replacement fonts often run wider or narrower. Adjust tracking in the Character panel, or scale the text slightly with Free Transform. For names inside ornaments, keep them centred by aligning to the ornament layer with the Move tool alignment buttons.

Tamil, Telugu and other Indian scripts

Templates with Indian-language text need Unicode fonts and the right text engine. Go to Preferences > Type and select the World-Ready Layout (or Middle Eastern and South Asian) option, then restart. Without it, conjuncts and vowel signs may display incorrectly even when the font is installed.

Preventing the problem in your own templates

  • Keep a fonts folder: store every font you use in a backed-up folder with your templates.
  • Limit your font list: two or three dependable pairs cover most albums.
  • Convert final text only if needed: if you share a PSD for printing, you can rasterise or convert text to shapes on a copy so it prints correctly anywhere.

Related help

Choosing reliable replacement fonts

When you cannot find the original, pick a replacement with a similar structure rather than a similar name. Look at the x-height, letter width and stroke contrast. For elegant scripts, choose one with connected letters and moderate swashes; very decorative scripts are hard to read for long names. For serif titles, classic high-contrast serifs replace each other well. Google Fonts and Adobe Fonts offer many families with licences that cover commercial use.

When text is already rasterised

Sometimes template text is flattened into pixels and cannot be edited. In that case, hide or delete the pixel layer, recreate the text with the Type tool, and match size and colour using the Eyedropper. Copy layer styles from another text layer if the original had a gold gradient or shadow.

Checking before export

Missing fonts can cause problems at the last minute. Before exporting print JPGs, open Type > Manage Missing Fonts once more. If it lists nothing, every text layer is rendering with an installed font. Then zoom through each text layer at 100 percent to check spacing, because replaced fonts often shift kerning slightly.

Sharing PSDs with other designers

If you hand off PSDs to another designer or a lab that edits files, include the fonts or a list with download links where the licence allows, or convert final text to shapes on a copy. This avoids the same missing-font problem on their computer.

If the PSD will not open at all, see how to fix ZIP extraction errors and how to download PSD files. For editing basics, read how to edit a wedding album PSD. Free templates to practise on are in the 12x36 wedding album category and the wedding invitation category, where text-heavy designs make font handling especially important.

Frequently asked questions

Why does my PSD say fonts are missing?

PSD files do not embed fonts. If the template uses a font that is not installed on your computer, Photoshop shows a warning.

Will the text look wrong if a font is missing?

It looks correct until you edit the layer. Once you type, Photoshop switches to a substitute font.

How do I fix Tamil text that looks broken in Photoshop?

Install a Unicode Tamil font and enable the World-Ready or South Asian text engine in Preferences > Type, then restart Photoshop.

Where can I find fonts that are safe for commercial album work?

Adobe Fonts and Google Fonts offer many families licensed for commercial use. Always check each font's licence.

Can I edit text that has been rasterised in a template?

Not directly. Hide the pixel layer and recreate the text with the Type tool, matching size and colour.
