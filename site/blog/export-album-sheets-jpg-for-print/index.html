Export Album Sheets as JPG for Print

After hours of design, the export step decides how the album actually prints. A wrong colour profile, low quality setting or confusing file names can undo good work. This guide covers the export settings, naming and checks that keep album sheets print-ready.

By Guru Moorthi · Updated 2026-10-24 · 4 min read

Keep a layered master

Always save the finished sheet as a layered PSD first. The JPG is a delivery copy; the PSD is what you return to for corrections. Store both in a clear folder structure, for example ClientName/PSD and ClientName/Print_JPG.

The right export settings

Format and quality

JPG at maximum quality (12 in Save As, or 100 in Export As) is the standard for most labs. Some labs accept TIFF for the best quality, but files are much larger. Never use Save for Web on print files; it is designed for small screen images.

Resolution

Check Image > Image Size before export. A 12x36 sheet should be 10800 x 3600 pixels at 300 pixels per inch. Export As can strip resolution metadata; File > Save a Copy as JPG keeps it, which some lab software expects.

Colour profile

Most Indian labs print from sRGB JPGs. Convert with Edit > Convert to Profile > sRGB IEC61966-2.1 and tick Embed Colour Profile when saving. Do not convert to CMYK unless the lab explicitly asks; our RGB vs CMYK guide explains why.

Bit depth

JPG supports only 8 bits per channel. If you edited in 16-bit, Photoshop converts automatically, but gradients can band. Add 0.5 to 1 percent noise to large gradient areas before export to prevent visible steps.

Naming files in page order

Labs print in file name order, so use numbers with leading zeros: 00_Cover, 01_Sheet, 02_Sheet up to 40_Sheet. Avoid spaces, special characters and names like final_final2.jpg. Include the client name or order number in the folder name rather than every file.

Exporting many sheets at once

For a full album, use File > Scripts > Image Processor. Select the PSD folder, choose JPG at quality 12, tick Convert Profile to sRGB, and set an output folder. Alternatively, build a batch action as described in Photoshop actions for album designers.

Checks before sending

  • Open every JPG: look at each file at fit-to-screen to catch missing photos or hidden layers.
  • Check the fold: no faces or text across the centre of spreads.
  • Check edges: backgrounds extend fully to the edge; text sits inside the safe area.
  • Spell names and dates: read every text element once more.
  • Confirm file count: the number of JPGs matches the agreed sheet count plus cover.

Covers need separate attention

Covers often have spine and wrap areas, so their dimensions differ from inner sheets. Export them separately and label clearly. See album cover dimensions for sizes.

Sending to the lab

Zip the folder, name it clearly, and send through the lab's preferred method. Keep the ZIP under the lab's upload limit by splitting if needed. Our guide to preparing and sending files to the lab covers delivery, and making a PDF for client approval covers the approval stage before export.

Practise with free sheets

Export As vs Save a Copy

Photoshop offers two main routes. Export As is fast and supports batch export of artboards, but by default it can omit resolution metadata and may convert colours to sRGB without telling you. Save a Copy (or Save As in older versions) with JPG keeps the resolution value, embeds the profile you choose and lets you set quality 0 to 12. For print work, Save a Copy is the more predictable option.

What about PNG and TIFF?

PNG is lossless but rarely accepted by album labs and creates huge files at 10800 x 3600 pixels. TIFF is accepted by some premium labs; use LZW compression and flatten layers. If in doubt, ask the lab for its preferred format.

File size expectations

A 12x36 JPG at quality 12 usually weighs 15 to 40 MB, depending on detail. If your files are only 2 to 3 MB, check that you have not exported at low quality or reduced size by mistake. If they are over 60 MB, check for unnecessary noise or very detailed textures.

Archiving after delivery

Once the lab confirms the files, archive the layered PSDs, final JPGs, fonts used and the client's approved proof together. Store at least two copies on different drives. Clients often return months later for a parents' copy or a reprint, and an organised archive turns that into quick, easy work.

A final quality pass

Before zipping, view all JPGs as a slideshow at full screen. Seeing them in sequence reveals repeated photos, uneven brightness between sheets and inconsistent text positions more clearly than checking files one by one.

Test your export settings on a sheet from the 12x36 wedding album category or the 12x30 album category and compare a test print with your screen.

Frequently asked questions

What JPG quality should I use for album printing?

Use maximum quality: 12 in Save As or 100 in Export As.

Should I export album sheets in CMYK?

Usually not. Most labs print from sRGB JPGs. Use CMYK only if your lab specifically asks.

How should I name album files for the lab?

Use numbered names with leading zeros, such as 00_Cover, 01_Sheet and 02_Sheet, so they sort in page order.

Why is my exported JPG showing 72 DPI?

Export As can drop resolution metadata. Use Save a Copy as JPG or set the resolution in Image Size without resampling.

How big should a 12x36 album JPG file be?

Usually between 15 and 40 MB at maximum quality, depending on image detail.
