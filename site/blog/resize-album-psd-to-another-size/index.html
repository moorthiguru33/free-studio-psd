How to Resize an Album PSD to Another Size

Studios often find the perfect template in one size but need to print another, for example a 12x36 design for a 12x30 album. Because album sizes have different proportions, you cannot simply scale the file without distortion or cropping. This guide shows how to adapt a layout properly in Photoshop.

By Guru Moorthi · Updated 2026-10-17 · 3 min read

Understand the proportions

A 12x36 spread has a 1:3 ratio; a 12x30 spread is 1:2.5; a 14x40 spread is about 1:2.86. Scaling a 12x36 design to 12x30 by changing only the width would squeeze everything horizontally, making circles oval and faces narrow. The right approach is to change the canvas, then rearrange.

Method 1: Same height, less width (12x36 to 12x30)

  • Open the PSD and save a copy with the new size in the name.
  • Image > Canvas Size. Set width to 30 inches (9000 pixels at 300 DPI) and anchor in the centre. Photoshop crops 3 inches from each side.
  • Move the outer frames inward so nothing important is cut. Reduce gaps between frames slightly.
  • Reposition the centre fold guide to 15 inches.
  • Stretch or extend backgrounds only if they are plain textures; otherwise move or rescale ornaments proportionally with Shift held.

Method 2: Different height (12x36 to 14x40)

  • Image > Image Size with Resample ticked. Scale proportionally so the height becomes 14 inches (4200 pixels). The width becomes 42 inches.
  • Then use Canvas Size to trim the width to 40 inches, anchored in the centre.
  • Adjust frames near the edges as in Method 1.

Upscaling a template slightly is usually acceptable for vector shapes and text, but raster textures can soften. Check at 100 percent.

Working with photo frames

Clipping-mask frames move with their photos if you link or group them. Select a frame and its clipped photo together before moving. Resize frames with Ctrl+T while holding Shift for proportional scaling. If a frame shape changes, re-fit the photo inside it.

Text and ornaments

Text layers and shape layers scale cleanly. Raster ornaments such as florals are best scaled down rather than up. Keep ornaments away from the new safe area at the edges.

Changing resolution

Converting a 300 DPI template to 200 DPI for a lab that prefers it is done with Image > Image Size with Resample ticked. Going from 200 to 300 DPI adds pixels but no real detail, so only do it if the lab insists.

Use the right template when possible

Adapting takes time. If a similar design exists in your target size, start from it. Browse the 12x30 album PSDs, 12x36 wedding album PSDs or 12x18 album PSDs.

Final checks

  • Confirm pixel dimensions with the lab; see wedding album sizes in India.
  • Check the safe area and centre fold.
  • Save the layered PSD, then export the print JPG.

Once you have adapted one spread successfully, save it as a template in the new size. Most albums reuse a handful of layouts, so converting five or six favourite designs once is far quicker than resizing every sheet for every client.
