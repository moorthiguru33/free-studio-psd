Photo Print Sizes in Pixels at 300 and 200 DPI

To print a photo or album sheet sharply, the file needs enough pixels for the print size. The calculation is simple: pixels equal inches multiplied by DPI (dots per inch, often used interchangeably with PPI for digital files). This chart lists common Indian print and album sizes so you can set up documents correctly.

By Guru Moorthi · Updated 2026-10-24 · 3 min read

The formula

Width in pixels = width in inches x DPI. Height in pixels = height in inches x DPI. A 6x8 print at 300 DPI needs 1800 x 2400 pixels. If your file has fewer pixels, the lab must stretch it and the print may look soft.

Common photo print sizes at 300 DPI

  • 4x6 inches: 1200 x 1800 pixels
  • 5x7 inches: 1500 x 2100 pixels
  • 6x8 inches: 1800 x 2400 pixels
  • 8x10 inches: 2400 x 3000 pixels
  • 8x12 inches: 2400 x 3600 pixels
  • 10x12 inches: 3000 x 3600 pixels
  • 12x15 inches: 3600 x 4500 pixels
  • 12x18 inches: 3600 x 5400 pixels
  • 16x20 inches: 4800 x 6000 pixels
  • 16x24 inches: 4800 x 7200 pixels
  • 20x30 inches: 6000 x 9000 pixels

Album spreads at 300 DPI

  • 12x24 spread: 7200 x 3600 pixels
  • 12x30 spread: 9000 x 3600 pixels
  • 12x36 spread: 10800 x 3600 pixels
  • 14x40 spread: 12000 x 4200 pixels

Spread sizes are written height first, then full open width. See wedding album sizes in India for how spread and book sizes relate.

The same sizes at 200 DPI

Some labs accept 200 DPI for albums because it produces smaller files that are still sharp at normal viewing distance. At 200 DPI a 12x36 spread is 7200 x 2400 pixels, 12x30 is 6000 x 2400 and 12x18 is 3600 x 2400. Ask your lab which they prefer; do not assume.

Changing DPI without changing pixels

In Photoshop, Image > Image Size shows the pixel dimensions and the print size. If you untick Resample and change the resolution, the pixel count stays the same and only the print size changes. This is how you check what size a photo can print at. If you tick Resample, Photoshop adds or removes pixels, which changes image quality.

How large can my photo print?

Divide the pixel dimensions by 300 for excellent quality, or by 200 for good quality. A 6000 x 4000 pixel camera file prints at 20 x 13.3 inches at 300 DPI or 30 x 20 inches at 200 DPI. A 1080 x 1350 pixel phone screenshot prints at only about 3.6 x 4.5 inches at 300 DPI, which is why images taken from social media look soft in albums.

Viewing distance matters

Large prints viewed from further away need less DPI to look sharp. Album pages are viewed closely, so 300 DPI or the lab's recommended value is sensible. Wall posters can often use less; ask the lab.

Practical checks before printing

  • Check every photo frame in your layout: a small photo stretched into a large frame will print soft even if the canvas is 300 DPI.
  • View at 100 percent zoom in Photoshop to see real sharpness.
  • Export in sRGB unless your lab requests otherwise; see RGB vs CMYK for albums.
  • Use our print-ready PSD checklist.
