How to Add a Studio Logo or Watermark in Photoshop

Studios add their logo to preview images, social media posts and sometimes to album covers or end pages. A well-placed, subtle logo builds recognition without distracting from the photo. This guide shows how to add a logo or text watermark in Photoshop and automate it for many images.

By Guru Moorthi · Updated 2026-10-23 · 2 min read

Prepare your logo

Use a transparent PNG or a vector file of your logo, ideally in white and in dark versions so it works on light and dark images. Save it somewhere permanent, as actions will reference its location.

Add a logo to one image

  • Open the photo, then File > Place Embedded and choose your logo.
  • Scale with the corner handles while holding Shift if needed, then press Enter.
  • Move it to a corner, usually bottom right, with consistent margins.
  • Lower the layer opacity to around 40 to 70 percent so it is visible but subtle.
  • Optionally set the blend mode to Overlay or Soft Light for a more integrated look.

Text watermark

If you do not have a logo file, use the Type tool to type your studio name in a clean font. Add a subtle drop shadow via Layer Style so it reads on varied backgrounds. Keep it small.

Automate for many images

  • Open the Actions panel (Alt+F9) and create a new action named 'Watermark'.
  • Record: place the logo, position it using Align (select all, then align to the canvas corner), set opacity, then flatten and save or export.
  • Stop recording. Run it on a folder with File > Automate > Batch.

Images with different orientations may need separate actions for portrait and landscape. Test the action on a few files first.

Where to place it

  • Avoid faces and the main subject.
  • Use the same corner and size across a set for a professional look.
  • On album previews, place it away from the centre fold.

Should album print files have watermarks?

Generally no; clients pay for clean prints. Many studios include a small logo on the last page or the back cover instead. For preview PDFs, a light watermark is common; see making an album PDF for client approval.

Protecting work realistically

A watermark discourages casual copying but cannot prevent determined misuse. Combine it with low-resolution previews and clear agreements. Avoid oversized watermarks across the whole photo, which spoil the client's experience.

Logo on studio backgrounds and frames

If you create studio prints with a background PSD, add the logo as a separate layer so you can remove it for clients who prefer a clean print. Our studio background PSD collection and album cover PSDs are good starting points.

Use your own logo only

Only use logos you own or have rights to. Do not add brand logos of camera makers, labs or other businesses to client images without permission.
