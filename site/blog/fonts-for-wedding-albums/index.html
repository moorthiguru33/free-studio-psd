Choosing Fonts for Wedding Album Designs

Pair one decorative script font with one clean sans-serif for balance.

Avoid using more than two or three fonts in one album.

Make names larger and supporting text smaller for a clear hierarchy.

If a PSD uses a missing font, Photoshop will ask you to replace it; choose a similar style.
