Album Cover Dimensions: Sizes for 12x36, 12x30 and 12x18 Albums

Album cover files confuse many new designers because the cover is not the same size as an inside spread. This guide explains how cover sizes relate to album sizes and what to ask your lab before you design.

By Guru Moorthi · Updated 2026-10-17 · 2 min read

The closed size is half the spread

A 12x36 album opens to a 12x36 inch spread, so the closed book (and the front cover) is 12 inches tall and 18 inches wide, landscape. A 12x30 album closes to 12x15. A 12x18 spread album closes to 12x9, and so on. Start any cover design from the closed size.

Front-only covers vs wrap-around covers

Some labs print only a front panel that is fixed onto a padded or acrylic cover. In that case the file is simply the closed size plus the lab's bleed, for example 12.25 x 18.25 inches for a 12x18 front with 0.125 inch bleed on each side.

Other labs print a full wrap: back cover + spine + front cover + extra margin that folds around the board. The width is roughly 2 x closed width + spine width + 2 x wrap margin. Spine width depends on the number of sheets and paper thickness, so it changes from album to album. Always download the lab's cover template for the exact sheet count.

Pixel sizes at 300 DPI

  • 12x18 front: 5400 x 3600 pixels.
  • 12x15 front: 4500 x 3600 pixels.
  • 12x24 front (for 12x48 spreads): 7200 x 3600 pixels.

Add bleed and wrap margins to these numbers as your lab requires.

Design tips

  • Use one strong couple photo; covers with many small photos look like the inside pages.
  • Keep names and the date large and centred on the front panel, well inside the safe area.
  • On wrap-around covers, keep the spine simple: names or initials only, centred.
  • Avoid fine script fonts on textured or leather-look covers; they lose detail.
  • Match the cover palette to the album's opening spread.

Using a cover PSD from this site

Our album cover PSDs are designed as front panels. Check the pixel size on the design page, place it on the front panel of your lab's template, and extend the background into the bleed. Then add the spine and back cover from the same colour palette.
