48	Cómo elegir el umbral de blanco y negro
49	El brillo de cada píxel (0 = negro, 255 = blanco) se compara con el umbral. El valor predeterminado de 160 sirve para la mayoría de documentos de oficina. Súbelo (180–200) si desaparece texto claro o fino; bájalo (120–140) si el papel gris, las manchas o un fondo de color se convierten en motas negras. Ejecútalo una vez, revisa el resultado y ajusta: solo lleva unos segundos.

68	Qué pasa con el texto
69	Para garantizar que se elimina todo el color –incluido el de imágenes, degradados, transparencias y gráficos incrustados–, cada página se renderiza y se guarda como imagen. Las páginas se ven exactamente como el original, pero en gris, y el texto ya no se puede seleccionar ni buscar. Si necesitas texto con búsqueda, aplica [OCR PDF](/ocr-pdf/) al resultado, que vuelve a añadir una capa de texto invisible. Conserva el original en color para editarlo.
