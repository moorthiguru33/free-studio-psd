43	How image compression works
44	Digital photos contain far more information than the human eye can detect at normal viewing size. Compression exploits this in two ways.
45	**Lossy compression** (JPG, WebP, AVIF) discards fine detail that you are unlikely to notice: subtle colour variation inside smooth areas like skies and skin, and high-frequency texture that is lost anyway when an image is viewed on a phone screen. JPG divides the image into 8×8 pixel blocks, converts each block into frequencies and rounds off the less important ones; the quality setting controls how aggressive that rounding is. WebP and AVIF use more modern prediction techniques borrowed from video codecs, so they reach the same visual quality with considerably fewer bytes.
46	**Lossless compression** (PNG) keeps every pixel exactly. The file gets smaller only by describing the same pixels more efficiently. To make PNGs dramatically smaller, {brand} uses colour quantisation: it reduces the image to an optimised palette of up to 256 colours, chosen to represent the original as closely as possible, and then stores it losslessly. For logos, icons, charts, screenshots and illustrations this typically cuts the size by 60–80% with no visible change, and transparency is preserved.
47	Resizing has the largest effect of all. Halving the width and height of an image removes three quarters of its pixels, so a 4000-pixel phone photo scaled to 1600 pixels is already around 85% smaller before any compression is applied.

105	Will compression reduce quality?
106	At sensible settings, not visibly. Quality 75–85 JPG or WebP is indistinguishable from the original for most people when viewed at normal size. Artefacts become noticeable at very low quality – blockiness in smooth gradients, halos around sharp edges and smeared fine texture. If you see them, raise the quality or allow a slightly larger target size.
107	Re-compressing an already compressed JPG again and again does slowly degrade it, because each pass discards a little more detail. Always start from the best original you have, and keep that original safe. Screenshots and graphics with sharp text compress best as PNG palette images or high-quality WebP; JPG tends to blur text edges.

119	Screen versus print
120	Compression settings for screens and for print are different. Screens show roughly 100–200 pixels per inch at normal viewing distance, so web images can be modest in size and use moderate quality. Printers need around 300 pixels per inch at the final print size: an A4 photo print needs roughly 2480×3508 pixels. For print, keep the full resolution, use quality 90 or higher and stay with JPG, which every print shop accepts. Never print from an image that was compressed to a small KB target for a web form – the lost detail cannot be recovered.
