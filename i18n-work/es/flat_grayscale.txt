48	Choosing the black & white threshold
49	Each pixel's brightness (0 = black, 255 = white) is compared with the threshold. The default of 160 works for most office documents. Raise it (180–200) if light or thin text disappears; lower it (120–140) if grey paper, stains or a coloured background turn into black speckles. Run it once, check the result, and adjust – it only takes seconds.

68	What happens to text
69	To guarantee every colour is removed – including colours inside images, gradients, transparency and embedded graphics – each page is rendered and saved as an image. The pages look exactly like the original in grey, but text is no longer selectable or searchable. If you need searchable text, run [OCR PDF](/ocr-pdf/) on the result, which adds an invisible text layer back. Keep your colour original for editing.
70	Printing in grayscale without converting
71	Most print dialogs have a *grayscale* or *black and white* option, which is enough for one-off printing at home. Converting the file is better when you send it to someone else, upload it to a portal that rejects colour, want consistent results on any printer, or need a smaller file.
72	Can a grayscale PDF be turned back into colour?
73	No – the colour information is removed. There is no reliable way to restore the original colours from a grey version, so always keep the colour original.
