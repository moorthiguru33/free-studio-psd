40	Choosing JPG to PNG, WebP or SVG
41	PNG is the safe default for transparency because every program supports it. If the image is for a website and file size matters, WebP with transparency is usually several times smaller than PNG for photos and works in every current browser – pick WebP in the format menu with the same transparency option. If the image is a simple logo or icon with few colours, the 'SVG (trace)' option turns it into a vector file that scales to any size; it works best for flat, high-contrast artwork rather than photos. For app icons and favicons, PNG remains the standard. Whatever you choose, keep the original JPG so you can convert again later if your needs change.
42	Making a JPG background transparent
43	JPG files cannot contain transparency, so a logo or signature saved as JPG always has a solid background – usually white. When 'Make white background transparent' is ticked, every pixel that is close to pure white becomes transparent, and slightly off-white pixels at the edges become partly transparent. This removes the white box around a logo or a scanned signature while keeping the edges smooth.

49	Does converting to PNG improve quality?
50	No – and this is a common misunderstanding. Converting a JPG to PNG keeps the image exactly as it is, including any JPG compression artefacts already in it. It does not add detail or sharpen anything. What PNG does is stop further loss: every time you edit and re-save a JPG, a little more detail is discarded, while a PNG can be edited and saved endlessly with no further change.

82	Why is the PNG so much bigger?
83	A JPG stores a simplified version of the photo, which is why it is small. PNG stores every pixel exactly, and photos have millions of slightly different pixels, so a lossless file is necessarily larger – a 400 KB JPG photo can become a 3–5 MB PNG. This is normal. If size matters, set a maximum width while converting, or choose WebP output with transparency instead of PNG.

97	Can PNG files be compressed?
98	Yes. PNG compression is lossless, so a converted photo stays large, but [Compress Image](/compress-image/) can reduce PNGs by 60–80% using colour quantisation – it picks the best 256-colour palette for the image. For logos, icons and screenshots the result is visually identical and transparency is kept. For photos, quantisation can show slight banding in smooth gradients; WebP is a better choice there.
