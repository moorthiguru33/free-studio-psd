71	Schützen Sie sich: QR-Phishing („Quishing“)
72	Gefälschte QR-Codes, die über Parkautomaten geklebt, per E-Mail verschickt oder auf Flyer gedruckt werden, sind eine wachsende Betrugsmasche: Sie führen zu Zahlungs- oder Anmeldeseiten, die echte nachahmen. Dieser Scanner öffnet nie automatisch einen Link. Lesen Sie vor dem Klicken die Adresse: Prüfen Sie die Schreibweise der Domain, seien Sie bei URL-Kürzern und ungewöhnlichen Endungen misstrauisch und geben Sie niemals Bank- oder Zugangsdaten auf einer Seite ein, die Sie über einen unerwarteten Code erreicht haben. Zahlungsaufforderungen sollten Sie in Ihrer Bank- oder Bezahl-App begleichen, nicht auf einer Website, die von einem Aufkleber aus geöffnet wurde.
73	Warum lässt sich mein QR-Code nicht scannen?
74	Das Bild ist zu unscharf oder der Code zu klein – enger zuschneiden oder das Foto bei gutem Licht wiederholen.
75	Ein Teil des Codes ist abgeschnitten oder verdeckt; die drei Eckquadrate müssen sichtbar sein.
76	Sehr geringer Kontrast oder farbige Hintergründe – der Scanner probiert invertierte Farben aus, aber ein blasser Code auf einem unruhigen Foto kann trotzdem scheitern.
77	Ein sehr großes Logo oder ein beschädigter Druck übersteigen die Fehlerkorrektur des Codes.
78	Es ist kein QR-Code: Data Matrix, Aztec und PDF417 werden nur gelesen, wo die Barcode-API des Browsers sie unterstützt.

103	Wie ein QR-Code Daten speichert
104	Ein QR-Code (Quick Response, „schnelle Antwort“) ist ein zweidimensionaler Matrixcode, den Denso Wave 1994 zur Verfolgung von Autoteilen erfand. Die drei großen Eckquadrate zeigen dem Scanner, wo der Code liegt und wie er ausgerichtet ist; das kleinere Ausrichtungsquadrat und die Taktmuster helfen, Perspektive und gewölbte Oberflächen auszugleichen. Die übrigen Module speichern die Daten plus Reed-Solomon-Fehlerkorrekturcodes – deshalb lässt sich ein Code auch lesen, wenn ein Teil verschmutzt, beschädigt oder von einem Logo verdeckt ist: bis zu 7 %, 15 %, 25 % oder 30 %, je nach bei der Erstellung gewählter Fehlerkorrekturstufe. Ein einzelner QR-Code fasst bis zu 4296 alphanumerische Zeichen oder 7089 Ziffern, auch wenn die meisten nur einen kurzen Weblink enthalten.
105	WLAN-, Kontakt- und Termin-Codes lesen
106	Viele QR-Codes enthalten statt eines Links strukturierten Text. Ein WLAN-Code sieht so aus: WIFI:T:WPA;S:Netzwerkname;P:Passwort;; (der Netzwerkname steht nach S:, das Passwort nach P:) – so können Sie das Passwort auf einen Laptop kopieren, der keine Codes scannen kann. Kontakt-Codes enthalten eine vCard (BEGIN:VCARD … END:VCARD) oder eine MeCard; kopieren Sie den Text in eine .vcf-Datei, um ihn in Ihr Adressbuch zu importieren. Termin-Codes enthalten ein VEVENT mit Titel sowie Start- und Endzeit, das Sie in einen Kalender einfügen können. Zahlungscodes beginnen mit einem Schema wie bitcoin: oder upi:, gefolgt von Adresse und Betrag; bestätigen Sie den Empfänger immer in Ihrer Wallet oder Banking-App.

143	Barrierefreiheit
144	Ergebnisse werden als Text angezeigt, sodass Screenreader den Inhalt jedes Codes vorlesen, und Links sind normale, per Tastatur erreichbare Links. Wer Mühe hat, das Smartphone auf einen kleinen gedruckten Code zu richten, kann ihn aus bequemer Entfernung fotografieren, danach zuschneiden oder vergrößern und das Ergebnis in beliebiger Textgröße lesen.
145	Warum ein Browser-Scanner statt einer App?
146	Viele kostenlose Scanner-Apps aus den App-Stores zeigen Vollbildwerbung, verlangen Zugriff auf Kontakte oder Standort und senden jeden gescannten Link für „Analysen“ an ihre eigenen Server oder leiten ihn über eine Tracking-Domain um. Eine Webseite braucht keine Installation und keine Berechtigung außer der Kamera, die Sie nur für einen Besuch erteilen können. Da diese Seite lokal decodiert und Links nie umschreibt, ist die angezeigte Adresse genau die, die im Code steht, und Ihr Scanverlauf existiert nur im geöffneten Tab, bis Sie ihn schließen.
