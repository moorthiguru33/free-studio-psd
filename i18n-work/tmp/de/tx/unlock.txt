90	Wie entferne ich das Passwort eines PDFs?
91	PDF hier ablegen, Passwort eingeben und auf „Entsperren“ klicken. Sie erhalten eine Kopie, die sich ohne Passwort öffnet.
92	Kann ich ein PDF kostenlos entsperren?
93	Ja, ohne Limits, Wasserzeichen oder Registrierung.
94	Ist es sicher?
95	Ja. Datei und Passwort bleiben in Ihrem Browser; nichts wird hochgeladen.
96	Kann ich ein PDF ohne Passwort entsperren?
97	Wenn es nur Einschränkungen hat (Drucken, Kopieren, Bearbeiten), ja – lassen Sie das Feld leer. Wenn zum Öffnen ein Passwort nötig ist, müssen Sie es kennen; dieses Tool knackt keine Passwörter.
98	Kann ich ein schreibgeschütztes PDF entsperren?
99	Ja. Schreibgeschützte PDFs haben meist nur Bearbeitungssperren, die sich ohne Passwort aufheben lassen.
100	Kann ich ein PDF-Passwort auf Mac, iPhone oder Android entfernen?
101	Ja. Das Tool funktioniert in jedem modernen Browser auf jedem Gerät.
102	Kann ich mehrere PDFs auf einmal entsperren?
103	Ja, wenn sie dasselbe Passwort haben. Die Ergebnisse werden als ZIP heruntergeladen.
104	Ändert sich der Inhalt?
105	Nein. Seiten, Text, Bilder und Links bleiben exakt erhalten.
106	Ist es legal, ein PDF zu entsperren?
107	Eigene Dateien oder Dateien, für die Sie eine Erlaubnis haben, dürfen Sie entsperren. Entfernen Sie keinen Schutz von Dokumenten, auf die Sie nicht zugreifen dürfen.
108	Wie entsperre ich ein PDF?
109	PDF ablegen. Hat es nur Einschränkungen (kein Drucken oder Kopieren), werden sie sofort aufgehoben. Ist zum Öffnen ein Passwort nötig, geben Sie das Ihnen bekannte Passwort ein und laden Sie eine entsperrte Kopie herunter.
110	Kann ich ein PDF ohne Passwort entsperren?
111	Berechtigungseinschränkungen lassen sich ohne Passwort aufheben. Ein PDF, das zum Öffnen ein Passwort braucht, ist verschlüsselt, und dieses Tool knackt oder errät keine unbekannten Passwörter – Sie benötigen das Passwort von der Person, die Ihnen die Datei geschickt hat.
112	Wie entsperre ich ein PDF zum Bearbeiten?
113	Beim Entsperren werden die Einschränkungen aufgehoben, die Bearbeiten, Kopieren oder Drucken verhindern. Danach können Sie die Datei im PDF-Editor oder in jeder anderen App öffnen.
