44	Die dunklen Pixel in der Miniatur jeder Seite werden analysiert. Markiert werden Seiten, auf denen fast nichts gedruckt ist: ganz weiß oder nur mit Scannerstaub. Werfen Sie vor dem Speichern immer einen Blick auf die markierten Miniaturen.

106	Wie lösche ich Seiten aus einem PDF?
107	Legen Sie das PDF ab, klicken Sie auf die zu entfernenden Seiten (oder geben Sie einen Bereich ein), dann auf Seiten löschen, und laden Sie herunter.
108	Kann ich mehrere Seiten auf einmal löschen?
109	Ja. Geben Sie einen Bereich wie 2,5-8 ein oder klicken Sie auf beliebig viele Miniaturen.
110	Kann es leere Seiten automatisch entfernen?
111	Ja. Klicken Sie auf Leere Seiten markieren, um leere Seiten auszuwählen, prüfen Sie sie und löschen Sie sie.
112	Kann ich etwas rückgängig machen?
113	Ja. Nutzen Sie Rückgängig, um frühere Markierungen wiederherzustellen, oder klicken Sie auf eine markierte Miniatur, um sie zu behalten.
114	Verringert das Löschen von Seiten die Qualität?
115	Nein. Die verbleibenden Seiten werden unverändert kopiert.
116	Wird mein PDF hochgeladen?
117	Nein. Alles geschieht in Ihrem Browser.
118	Ist es kostenlos?
119	Ja, ohne Wasserzeichen, Limits oder Registrierung.
120	Kann ich Seiten am Handy löschen?
121	Ja. Tippen Sie im Browser eines beliebigen Handys oder Tablets auf die Miniaturen.
122	Verschwinden gelöschte Seiten wirklich?
123	Ja. Sie sind in der neuen Datei überhaupt nicht enthalten.
124	Wie entferne ich Seiten aus einem PDF?
125	Öffnen Sie das PDF, tippen Sie auf die Miniaturen der unerwünschten Seiten (oder geben Sie Bereiche wie 2,5-8 ein) und laden Sie die neue Datei herunter. Leere Seiten lassen sich automatisch markieren.
126	Kann ich PDF-Seiten kostenlos löschen?
127	Ja, ohne Konto, Wasserzeichen oder Seitenlimit; die Seiten werden auf Ihrem Gerät gelöscht.
