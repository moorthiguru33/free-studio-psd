48	Statische und dynamische QR-Codes im Vergleich
49	Es gibt zwei Arten von QR-Codes. Ein **statischer** Code speichert Ihren Inhalt (die URL, die WLAN-Daten) direkt im Schwarz-Weiß-Muster. Ein **dynamischer** Code speichert einen Kurzlink zum Server des Anbieters, der dann auf Ihre eigentliche URL weiterleitet. Dynamische Codes erlauben es, das Ziel später zu ändern und Scans zu zählen – aber nur, solange Sie den Anbieter bezahlen: Läuft das Abo aus oder schließt der Anbieter, funktionieren alle gedruckten Codes nicht mehr. Viele „kostenlose“ Generatoren erstellen standardmäßig dynamische Codes und deaktivieren sie nach einer Testphase – ein häufiges Ärgernis für Restaurants und kleine Unternehmen, deren Speisekarten plötzlich nicht mehr scannbar waren.

115	Einen QR-Code gestalten, der immer lesbar ist
116	**Achten Sie auf starken Kontrast.** Dunkle Module auf hellem Hintergrund. Manche älteren Scanner lesen helle Codes auf dunklem Grund (invertiert) nicht.
117	**Übertreiben Sie es nicht mit dem Stil.** Punkte und Verläufe sehen toll aus; prüfen Sie, dass sich die dunkelste und die hellste Farbe noch deutlich unterscheiden.
118	**Ruhezone einhalten.** Der weiße Rand um den Code (mindestens vier Module) hilft Kameras, ihn zu finden – nicht wegschneiden.
119	**Logos bis 20–25 % der Fläche.** Größere Logos verdecken selbst bei Stufe H zu viele Module.
120	**Weniger Inhalt = größere Module.** Eine kurze URL ergibt einen einfacheren Code, der sich aus größerer Entfernung scannen lässt.
121	**Immer testen** – mit zwei oder drei Smartphones (iPhone-Kamera, Android-Kamera und eine Scanner-App), bevor Sie Tausende Exemplare drucken.
122	Fehlerkorrekturstufen
123	QR-Codes enthalten redundante Daten, damit sie auch funktionieren, wenn ein Teil des Codes beschädigt, verschmutzt oder von einem Logo verdeckt ist. Es gibt vier Stufen: L stellt etwa 7 % beschädigter Daten wieder her, M etwa 15 %, Q etwa 25 % und H etwa 30 %. Höhere Stufen machen den Code dichter. Verwenden Sie M für saubere digitale Nutzung, Q für den Außendruck und H, wenn Sie ein Logo hinzufügen – {brand} schaltet automatisch auf H, sobald Sie eines hochladen.
124	Druckgröße und Scanabstand
125	Als Faustregel lässt sich ein QR-Code aus etwa der zehnfachen Breite scannen: ein 2-cm-Code aus 20 cm, ein 10-cm-Code auf einem Plakat aus etwa 1 Meter und ein 1-m-Code auf einem Banner aus rund 10 Metern. Auf Visitenkarten sind 2–2,5 cm das praktische Minimum. Verwenden Sie für den Druck SVG oder PDF, damit die Kanten in jeder Größe gestochen scharf bleiben, oder PNG ab 2000 Pixel.

140	WLAN-QR-Codes
141	Mit einem WLAN-Code verbinden sich Gäste mit Ihrem Netz, indem sie einfach die Kamera darauf richten – ohne lange Passwörter zu buchstabieren. Geben Sie den Netzwerknamen (SSID) exakt so ein, wie er angezeigt wird, dazu das Passwort und den Sicherheitstyp (WPA/WPA2/WPA3 bei fast allen modernen Routern, WEP bei sehr alten, keiner bei offenen Netzen). Aktivieren Sie „versteckt“, wenn Ihr Netz seinen Namen nicht aussendet. iPhones (ab iOS 11) und Android-Smartphones (ab Android 10) lesen WLAN-Codes mit der integrierten Kamera. Eine eigene Seite mit Tipps finden Sie unter [WLAN-QR-Code-Generator](/wifi-qr-code-generator/).
142	vCard-QR-Codes für Visitenkarten
143	Ein vCard-Code enthält Ihren Namen, Ihre Firma, Position, Telefonnummern, E-Mail, Website und Adresse. Halten Sie ihn kompakt: Jedes zusätzliche Feld fügt Daten hinzu und macht den Code dichter; auf einer kleinen Karte gehört nur hinein, was wirklich gebraucht wird. 144	Datenschutz
145	Der QR-Code wird vollständig in Ihrem Browser erstellt. Was Sie eingeben (Webadressen, WLAN-Passwörter, Telefonnummern, Kontaktdaten), wird nie an {brand} oder an Dritte gesendet. Der fertige statische Code leitet über keinen Server um – niemand verfolgt also, wer ihn wann und wo scannt.
146	Anbieter dynamischer Codes stehen dagegen zwischen jeder Person, die Ihren Code scannt, und Ihrer Website und protokollieren die Scan-Daten. Das kann fürs Marketing nützlich sein, man sollte es aber vor dem Drucken wissen.
147	So funktioniert ein QR-Code
148	QR steht für „Quick Response“ (schnelle Antwort). Das Format wurde 1994 von Denso Wave, einem Unternehmen der Toyota-Gruppe, zur Verfolgung von Autoteilen erfunden und ist heute ein internationaler Standard (ISO/IEC 18004). Ein QR-Code ist ein Raster aus quadratischen Modulen. Die drei großen Quadrate in den Ecken (Positionsmarken oder „Augen“) helfen der Kamera, den Code zu finden und seinen Winkel zu bestimmen. Kleinere Ausrichtungsmuster korrigieren die Perspektive, Taktlinien legen das Raster fest, und Formatinformationen teilen dem Scanner mit, welche Fehlerkorrekturstufe und welche Maske verwendet werden. Der Rest des Rasters enthält Ihre Daten, codiert mit Reed-Solomon-Fehlerkorrektur – derselben Mathematik, dank der zerkratzte CDs noch abspielbar sind.
149	QR-Codes gibt es in 40 Versionen, von 21×21 Modulen (Version 1) bis 177×177 (Version 40). Je mehr Daten Sie codieren und je höher die Fehlerkorrektur, desto höher die Version – deshalb ergibt eine lange URL mit Logo einen dichteren Code als ein kurzer Link ohne. Ein Code der Version 40 fasst bis zu etwa 4296 alphanumerische Zeichen; damit er sich gut mit dem Smartphone scannen lässt, bleiben Sie aber besser deutlich unter einigen hundert Zeichen.

176	PNG, SVG oder PDF?
177	**PNG** ist ein Pixelbild – ideal für Websites, Folien, Social-Media-Beiträge und E-Mails. Wählen Sie eine passende Größe: 1000 Pixel für Bildschirme, 2000–4000 für den Druck. **SVG** ist ein Vektorformat: Der Code wird als Formen gespeichert und lässt sich ohne Unschärfe beliebig vergrößern, vom Aufkleber bis zur Gebäudeplane. Designer können ihn in Illustrator, Inkscape, Figma oder Affinity öffnen und die Farben ändern. **PDF** ist bereit für die Druckerei oder zum Einfügen in ein Dokument; bei Verläufen, Rahmen oder Logo enthält das PDF ein hochaufgelöstes Bild Ihres gestalteten Codes.
178	QR-Codes für Restaurants und Cafés
179	Speisekarten-Codes auf den Tischen gehören zu den beliebtesten Anwendungen. Verlinken Sie auf eine Speisekartenseite Ihrer eigenen Website oder ein dort gehostetes PDF – nicht auf einen dynamischen Link eines Drittanbieters, der ablaufen kann. Drucken Sie die Codes 4–5 cm breit auf Tischaufsteller, fügen Sie einen Rahmen mit „Scannen für die Speisekarte“ hinzu und laminieren Sie sie gegen Verschüttetes. Platzieren Sie einen WLAN-Code daneben, damit sich Gäste sofort verbinden. Wenn Sie die Karte ändern, aktualisieren Sie die Seite oder ersetzen Sie das PDF unter derselben Adresse – die gedruckten Codes funktionieren weiter.
180	Verpackungen, Produkte und Etiketten
181	Auf Verpackungen verlinken QR-Codes auf Anleitungen, Zutatenlisten, Garantieregistrierung, Videos oder Nachbestellseiten. Verwenden Sie eine kurze URL, damit der Code klein und einfach bleibt, halten Sie ihn von Falzen und gewölbten Kanten fern und nutzen Sie SVG, damit die Druckerei perfekt scharfe Kanten erhält. Wählen Sie auf kleinen Etiketten Fehlerkorrektur M ohne Logo, damit die Module so groß wie möglich sind.
182	Veranstaltungen, Flyer und Plakate
183	Termin-Codes können Datum, Uhrzeit und Ort direkt in den Smartphone-Kalender eintragen. Standort-Codes öffnen den Ort in der Karten-App. Platzieren Sie den Code auf Plakaten etwa auf Brusthöhe, fügen Sie im Rahmen eine klare Handlungsaufforderung hinzu („Scannen für Tickets“) und sorgen Sie für ausreichend Licht am Aushangort. Codes hinter Glas funktionieren, vermeiden Sie aber glänzende Laminierungen, die spiegeln.
184	Sicherheit: QR-Code-Betrug
185	Da Menschen einen QR-Code nicht mit bloßem Auge lesen können, kleben Betrüger manchmal gefälschte Codes über echte – an Parkautomaten, Plakaten oder Restauranttischen –, um Nutzer auf Phishing-Seiten zu leiten. Diese Masche wird auch „Quishing“ genannt. Wenn Sie Codes im öffentlichen Raum anbringen, kontrollieren Sie sie regelmäßig, erwägen Sie manipulationssichere Aufkleber und drucken Sie Ihre Domain unter den Code, damit erkennbar ist, wohin er führt. Prüfen Sie beim Scannen die URL-Vorschau Ihres Smartphones, bevor Sie sie öffnen, und geben Sie niemals Passwörter oder Zahlungsdaten auf einer Seite ein, die Sie über einen unerwarteten Code erreicht haben. Den Inhalt jedes Codes können Sie gefahrlos mit unserem [QR-Code-Scanner](/qr-code-scanner/) prüfen.

202	So scannen Sie einen QR-Code
203	Öffnen Sie auf dem **iPhone** die Kamera-App und richten Sie sie auf den Code; tippen Sie auf den eingeblendeten Link. Sie können auch den Code-Scanner zum Kontrollzentrum hinzufügen. Öffnen Sie auf **Android** die Kamera (die meisten Geräte ab Android 9 scannen automatisch) oder nutzen Sie Google Lens über die Suchleiste oder die Kamera-App. Laden Sie am **Computer** einen Screenshot oder ein Foto des Codes in unseren [QR-Code-Scanner](/qr-code-scanner/) hoch. WLAN-, Kontakt- und Termin-Codes lösen die passende Aktion aus (mit dem Netz verbinden, Kontakt speichern, zum Kalender hinzufügen), statt einen Link zu öffnen.
204	Ein Logo richtig einsetzen
205	Ein Logo macht einen Code sofort erkennbar und schafft Vertrauen, verdeckt aber einen Teil der Daten. Verwenden Sie eine einfache, kontrastreiche Version Ihres Logos (lieber ein Icon oder Monogramm als den vollen Schriftzug) als quadratisches oder rundes Bild, idealerweise mit weißem oder transparentem Hintergrund. Halten Sie es bei etwa einem Fünftel der Codebreite. Da der Code die Fehlerkorrektur braucht, um rund um das Logo zu funktionieren, sollten Sie ein großes Logo nicht mit sehr langem Inhalt kombinieren – das macht die Module klein und lässt weniger Spielraum für Fehler. Wenn Ihr Logo nur mit unruhigem Hintergrund vorliegt, stellen Sie es zuerst mit [Hintergrund entfernen](/remove-background/) frei.
206	Rahmen und Handlungsaufforderungen
207	Ein nackter QR-Code verrät nicht, was man bekommt; eine kurze Anweisung daneben gibt den Leuten einen Grund, das Smartphone zu zücken. Nutzen Sie die Rahmenoption für eine Beschriftung wie „Scannen für die Speisekarte“, „Scannen für WLAN“, „Scannen für 10 % Rabatt“ oder „Video ansehen“. Der Rahmen „Beschriftung darunter“ fügt einen Textstreifen unter dem Code hinzu; „Rahmen mit Beschriftung“ umgibt den Code mit einem farbigen Rand, was zudem eine saubere Ruhezone sichert, wenn der Code auf unruhigen Hintergründen oder Fotos steht. Beschränken Sie die Beschriftung auf zwei bis vier Wörter, damit sie auch klein lesbar bleibt.
208	Barrierefreiheit
209	Nicht jeder kann einen Code scannen: Manche haben ältere Smartphones, eine Sehbehinderung oder möchten es schlicht nicht. Drucken Sie, wo Platz ist, eine kurze, lesbare URL oder Telefonnummer als Alternative neben den Code und verwenden Sie einen beschreibenden Alternativtext, wenn Sie ein QR-Bild auf einer Website einbinden. Auf dem Bildschirm dient ein QR-Code vor allem dem Wechsel vom Computer zum Smartphone; auf dem Smartphone selbst ist ein normaler Link immer einfacher als ein Code.
210	QR-Codes in Dokumenten und Präsentationen
211	Mit einem QR-Code auf einer Folie kann Ihr Publikum Ihre Unterlagen, Umfrage oder Kontaktseite öffnen, während Sie weitersprechen. Platzieren Sie ihn in einer Ecke der letzten Folie, mindestens ein Fünftel der Folienhöhe groß, und lassen Sie ihn lange genug stehen, damit man ihn auch aus der letzten Reihe scannen kann. In Berichten, Lebensläufen und gedruckten Broschüren erspart ein kleiner Code neben einem Link das Abtippen langer Adressen. Laden Sie PNG mit 1000 Pixeln für PowerPoint, Google Präsentationen oder Keynote herunter oder SVG für Word- und InDesign-Layouts, in denen er scharf bleiben muss. Einen Code in ein vorhandenes PDF (eine Broschüre oder ein Ticket) setzen Sie mit [Bild zu PDF hinzufügen](/add-image-to-pdf/). Bei mehrseitigen Dokumenten lohnt sich ein eigener Code pro Abschnitt, damit Leser direkt zum passenden Online-Material gelangen statt auf eine allgemeine Startseite.

263	Ist dieser QR-Code-Generator wirklich kostenlos?
264	Ja. Unbegrenzt viele Codes, alle Designoptionen und alle Downloadformate – ohne Konto und ohne Wasserzeichen.
265	Laufen die QR-Codes ab?
266	Nein. Sie sind statisch: Der Inhalt steckt im Code selbst, er funktioniert also für immer.
267	Kann ich mein Logo hinzufügen?
268	Ja. Laden Sie ein Bild hoch; die Fehlerkorrektur springt automatisch auf H, damit der Code lesbar bleibt.
269	Darf ich die Codes kommerziell nutzen?
270	Ja. Verwenden Sie sie auf Produkten, Verpackungen, Speisekarten und in der Werbung – ohne Namensnennung.
271	Kann ich den Link nach dem Drucken ändern?
272	Bei einem statischen Code nicht. Lassen Sie ihn auf eine Seite zeigen, die Sie kontrollieren, und ändern Sie diese Seite.
273	Kann ich sehen, wie viele Personen scannen?
274	Statische Codes haben kein eingebautes Tracking. Fügen Sie der URL UTM-Parameter hinzu und werten Sie sie in Ihrer eigenen Analyse aus.
275	Welches Format eignet sich am besten für den Druck?
276	SVG oder PDF – Vektorformate, die in jeder Größe scharf bleiben.
277	Warum lässt sich mein QR-Code nicht scannen?
278	Meist wegen zu geringem Kontrast, einem zu großen Logo, einer abgeschnittenen Ruhezone oder zu kleinem Druck. Wählen Sie einen schlichteren Stil und testen Sie erneut.
279	Wird mein WLAN-Passwort irgendwohin gesendet?
280	Nein. Der Code wird in Ihrem Browser erstellt.
281	Wie groß sollte ein QR-Code sein?
282	Mindestens 2 cm auf Visitenkarten; allgemein etwa ein Zehntel des Scanabstands.
