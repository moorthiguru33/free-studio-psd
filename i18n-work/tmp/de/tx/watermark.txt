53	Welchen Schutz bietet ein Wasserzeichen?
54	Ein Wasserzeichen wird als Text oder Bild auf die Seite gezeichnet. Es ist eine deutliche sichtbare Aussage über Eigentum oder Status und schreckt vor beiläufigem Missbrauch ab, doch eine entschlossene Person mit einem PDF-Editor kann Objekte von einer Seite entfernen. Für stärkeren Schutz kombinieren Sie ein gekacheltes Wasserzeichen mit [PDF schützen](/protect-pdf/) und deaktivieren Bearbeiten und Kopieren, oder reduzieren Sie das Dokument mit [PDF reduzieren](/flatten-pdf/).
55	Logo-Wasserzeichen
56	Laden Sie Ihr Logo als PNG mit transparentem Hintergrund hoch, um das sauberste Ergebnis zu erhalten. Setzen Sie die Drehung auf 0°, wählen Sie eine Ecke und stellen Sie die Breite auf 15–25 % der Seite ein. Für ein dezentes Hintergrundlogo wählen Sie die Mitte, 50–60 % Breite und 10–15 % Deckkraft. Das Bild wird einmal eingebettet und auf jeder Seite wiederverwendet, sodass die Datei kaum größer wird.

114	Im Rahmen des Aufgabenlimits
115	Wie füge ich einem PDF ein Wasserzeichen hinzu?
116	PDF ablegen, Text eingeben oder Logo wählen, Deckkraft und Position anpassen und auf „Wasserzeichen hinzufügen“ klicken.
117	Kann ich mein Logo als Wasserzeichen verwenden?
118	Ja. Wählen Sie „Bild / Logo“ und laden Sie ein PNG oder JPG hoch. Transparente PNGs wirken am besten.
119	Kann ich das Wasserzeichen nur auf einige Seiten setzen?
120	Ja. Geben Sie einen Seitenbereich wie 1 oder 3-10 an.
121	Kann ich das Wasserzeichen transparent machen?
122	Ja. Stellen Sie die Deckkraft zwischen 5 % und 100 % ein.
123	Kann ich das Wasserzeichen über die ganze Seite wiederholen?
124	Ja. Wählen Sie die Anordnung „Kachel“.
125	Wird mein Dokument hochgeladen?
126	Nein. Das Wasserzeichen wird in Ihrem Browser hinzugefügt.
127	Kann ich mehrere PDFs auf einmal mit Wasserzeichen versehen?
128	Ja. Legen Sie mehrere Dateien ab und laden Sie ein ZIP herunter.
129	Lassen sich Wasserzeichen entfernen?
130	Ein Wasserzeichen ist eine sichtbare Markierung; jemand mit einem Editor könnte es entfernen. Kombinieren Sie es mit Passwortschutz und deaktiviertem Bearbeiten für stärkeren Schutz.
131	Werden andere Sprachen unterstützt?
132	Ja. Text-Wasserzeichen funktionieren auch mit nicht lateinischen Schriften.
133	Wie versehe ich ein PDF kostenlos mit einem Wasserzeichen?
134	PDF ablegen, Text eingeben (z. B. ENTWURF oder VERTRAULICH) oder ein Logo hochladen, Deckkraft, Drehung, Farbe und Position oder Kachel anpassen und herunterladen. Kostenlos, ohne Anmeldung und ohne zusätzliches Branding.
135	Kann ich einem PDF ein Wasserzeichen ENTWURF oder VERTRAULICH hinzufügen?
136	Ja. Geben Sie das Wort ein, drehen Sie es um 45°, stellen Sie eine Deckkraft von etwa 20–30 % ein, damit der Inhalt lesbar bleibt, und wenden Sie es auf alle Seiten oder einen Bereich an.
